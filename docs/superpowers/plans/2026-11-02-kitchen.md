# The Pokémon Kitchen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `/che-bien` page where players cook their bag's berries, drinks and sweets into dishes (12 known, 8 secret to discover) that give only positive care stats; dishes go to a "Món ăn" pocket of the bag.

**Architecture:** Postgres decides (a new migration: ingredients, recipes, dishes, discoveries, attempts; RPCs `kitchen_menu`, `kitchen_cook`), mirrored for `yarn dev` by a local engine on the same rules (`src/pages/KitchenPage/engine/rules.mjs`). Flavours live on the items (`items.mjs`), dishes in `recipes.mjs`; a test keeps both equal to the migration. The page draws dishes in SVG (`DishArt.tsx`).

**Tech Stack:** Postgres 17 + pgTAP, Node 22 `node --test`, React/Preact + styled-components, Puppeteer.

**Spec:** `docs/superpowers/specs/2026-11-02-kitchen-design.md`

## Global Constraints

- Stats: `power` (Sức mạnh, spicy), `beauty` (Sắc đẹp, dry), `happiness` (Hạnh phúc, sweet), `agility` (Linh hoạt, sour), `wisdom` (Trí tuệ, bitter), `friendship` (Thân thiện, every dish = ingredient count). Never negative.
- Flavour colours: spicy `#e5483b`, dry `#3b7be5`, sweet `#f07cb4`, bitter `#3fa463`, sour `#e8c022`.
- Stats formula: per flavour Σ potency / 10; 3 strongest kept (ties by flavour name); secret × 1.5 rounded up (friendship too).
- Pot: 2–4 ingredients. Failure: return `ceil(n / 2)` ingredients, the first ones of the sorted list; `near` = largest multiset overlap with a secret recipe not yet discovered.
- Errors: `bad_pot`, `not_food`, `missing`, `unknown_dish`.
- Secret recipes never reach the browser before they are discovered (server mode).
- Nothing in `server/src` except the route's loader name in `server.config.ts` (as `tui-do-page`). Never commit `server/dist/*`.
- Vietnamese copy; chunks ≤ 150 kB; no chunk cycle; reduced motion respected; no layout shift while cooking.

## Review Focus

- A failed pot's half: ingredients counted per kind (2 Cheri + 1 Lava → sorted [cheri, cheri, lava] → back [cheri, cheri]).
- `near` must ignore secret dishes already discovered and must never name an ingredient.
- Cooking a known dish from the free pot is a success (not a discovery).
- Two tabs cooking the same last ingredient: one `missing`, the shelf reloads.
- The header with 6 links at 961–1240 px must not overflow (breakpoints from the header fix).
