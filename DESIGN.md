# Pokédex Field Notes

## Overview

A field notebook meets a Pokémon encounter card: friendly, tactile and expressive, with quiet catalogue controls. Vietnamese interface, official English Pokémon names. The user's explicit priority is mobile widths 375–460px, compact text, lightweight artwork and smooth touch interaction. No Japan-market assumptions follow from the Pokémon subject.

The switchable Pikachu/Charizard/Gengar encounter is the signature. Keep personality there; avoid decorative noise in the catalogue. The home route is a hybrid discovery/product screen; detailed Pokémon and article routes retain immersive ink surfaces. Avoid the former busy full-screen backdrop and translucent stacked cards.

Runtime CSS is canonical (Model B): `src/assets/styles/main.css` defines the `--ink`, `--ink-soft`, `--canvas`, `--surface`, `--muted`, `--line`, `--red`, `--yellow`, `--mint`, `--focus`, `--radius-card`, `--font-body`, and `--font-display` tokens. This file mirrors those exact values. Styled components consume CSS variables directly; no independent theme adapter or generated palette.

## Colors

Ink carries headings, navigation and immersive surfaces. Canvas is a cool pale background, white is the catalogue surface. Yellow signals discovery; red belongs to the Poké Ball and small identity accents. Mint denotes the personal collection. Muted text is secondary, never the only indication of selected/caught status. Focus blue uses a 3px visible outline on light surfaces; immersive controls also have existing yellow focus treatments.

## Typography

Self-hosted Be Vietnam Pro supports Vietnamese at weights 400–800. Use 800 for short headings and Pokémon names; ordinary descriptions use 400/500. Dela Gothic One is confined to Latin exclamations behind artwork and existing detail display labels. Names truncate in catalogue cards; accessible link names retain the complete Pokémon name. Do not use uppercase for long Vietnamese prose.

## Layout

A single scroll owner (`BodyStyle`) preserves the existing app navigation/scroll restoration contract. Header remains outside it. Content max-width is 1240px, desktop gutter 40px, mobile gutter 18px. At <=680px: stacked encounter, two-column cards, search above two authored select controls. Main scroll indicators and horizontal chip indicators are hidden at the user's explicit request; touch, wheel and keyboard scrolling remain active. Other overflow regions inherit the global scrollbar baseline. No horizontal page overflow is accepted at 375, 390, 430 or 460px.

## Elevation & Depth

Borders and tonal surfaces establish hierarchy. Artwork uses a restrained drop shadow. The featured encounter rotates 1.5° on mobile, 2° on desktop. Only cards lift slightly on hover. Avoid blur on static content; reserve blur for modal backdrops. Respect reduced motion globally.

## Shapes

Rounded field cards: 20px shared container token, 14px mobile catalogue cards, 12px controls. Poké Ball geometry is circular. Shared AppSelect uses Radix Select with a fully authored popup, matching trigger width and 14px symmetric horizontal padding.

## Components

Header owns brand/navigation/search/menu. `FieldIcon` and `Pokeball` own new shared SVG symbols. `FeaturedEncounter` owns the three curated encounters; 480px WebP hero artwork and 192px catalogue WebPs are generated by `scripts/prepare-pokemon-art.mjs`. First 151 species are local; later species use existing official-artwork URLs with tiny sprite fallback. Card media reserves 115px on mobile. Shared route and list loading is a 24–32px Poké Ball, never a full-screen image.

Search is local over the cached name index. Type requests go through the existing RTK/proxy layer and load on demand. Controls have hover, focus, pressed and disabled states. Dialogs reuse `useDialog`, explicit close buttons and inert background. Details preserve their existing dynamic habitat colors and Shiny artwork behavior.

## Do's and Don'ts

- Prefer short Vietnamese labels and one clear action.
- Keep media dimensions stable and lazy-load catalogue images.
- Do not request an individual Pokémon payload for every catalogue card.
- Keep physical scroll indicators hidden in the app's main scroller per explicit user preference; never disable scrolling itself.
- Do not introduce fabricated Pokémon attributes, inactive buttons or layout shifts for feedback.


Select refinement (explicit user request): `src/components/common/Select` is the canonical single-select owner. Trigger padding is 14px on both sides; 1px border makes the measured content inset 15px. Mobile height is 44px. Radix owns keyboard/focus/typeahead and portal collision handling. The popup matches trigger width exactly, uses the same 12px radius and border token, and contains one stable native overflow viewport. Do not add auto-scroll buttons: their appearance resized the viewport and could move scroll from 10px to 158px. Selected and keyboard-highlighted items have distinct treatments; the complete accessible option name includes its generation description.


Practical detail data (type defenses and searchable movesets) uses white field-note cards over the immersive ink detail background. 16px card padding,20px container radius; table rows are compact and left aligned, learned-method badges right aligned. Version selectors reuse AppSelect.
